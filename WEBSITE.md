# Portfolio website

Live site: https://ramezwasfy.github.io/RamezWasfy/

GitHub Pages publishes the static files in `docs/` from the `main` branch. The
`.nojekyll` file serves these files directly. No build tools or server are required.

The homepage is `docs/index.html`; the 15 engineering notes are in `docs/blog/`.
Styles, interactive visuals, images, and fonts are included in `docs/`.

Edit these files and push to `main` to publish an update. Internal links and asset
paths must start with `/RamezWasfy/`, because this is a repository Pages site.

This copy was exported from the existing [Sites portfolio](https://ramez-wasfy.ramez1991.chatgpt.site/)
on 4 October 2026. The two copies are maintained independently; edits made in
Sites do not automatically sync to this repository. To refresh this copy, export
the static site again, apply the `/RamezWasfy/` prefix to local links and assets,
and update the site URLs in page metadata, `sitemap.xml`, and `robots.txt`.
